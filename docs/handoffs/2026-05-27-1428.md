## 4. Contexto necesario para la próxima sesión

### 4.1 Architecture nuevos componentes
- **StatusEffectComponent**: hijo runtime de Player + Enemy (instanciado en `_ready`). Trackea lifecycle, owner aplica side effects vía signals. Tiene también método público `tick(delta)` para tests headless sin scene tree.
- **EnemySkillData**: Resource .tres. R2_SKILL_TABLE const sigue como fallback defensivo. Accesores en enemy.gd usan .tres si disponible, fallback const si null/0.
- **PlayerSkillSystem**: autoload registrado en project.godot ANTES de SaveSystem (orden importa para load). 3 slots, signals, `_serialize_state/_restore_state` para persistencia.

### 4.2 Convenciones a seguir
- StatusEffectData `id` (StringName snake_case): &"burn", &"freeze", &"fractura", &"desequilibrio", &"bendicion", &"miasma", &"slow", &"stun", &"espiritu_marcial", &"post_dash_damage", &"post_dash_invis", &"muralla_estatica".
- Boss state ints: 100+ = Guardian, 200+ = Duelista, 300+ = Ignis, 400+ = Lyss. Próximos: 500+ Vael, 600+ heraldo override si necesita.
- Status synergy 30% chance is hardcoded en HitboxComponent + Projectile (`ELEMENT_STATUS_CHANCE`). Tunear acá.
- VULNERABLE.tres tiene id `fractura` (mismatch de filename intencional para no romper paths; ver comentario).
- POISON.tres tiene id `miasma` (mismo motivo).

### 4.3 Reglas canon vigentes
- **6 elementos**: NEUTRO(0), FUEGO(1), AGUA(2), TIERRA(3), VIENTO(4), LUZ(5), SOMBRA(6).
- **Triángulos**: primario FUEGO>TIERRA>AGUA>FUEGO + secundario VIENTO>LUZ>SOMBRA>VIENTO. Cross neutral 1.0.
- **Element synergy on-hit**: 30% chance. FUEGO=Quemadura, AGUA=Congelación, TIERRA=Fractura single-use, VIENTO=Desequilibrio, LUZ=Bendición (vampire heal source), SOMBRA=Miasma (bypass armor + halve Furia).
- **MIASMA bypass armor**: tick directo a health.take_damage. **MIASMA halve Furia**: player._on_hit_landed multiplica furia_mult *= 0.5 si has miasma.
- **FRACTURA consume on hit**: HurtboxComponent.receive_hit ejecuta `se.remove(&"fractura")` tras aplicar multiplicador.
- **DESEQUILIBRIO interrupt**: enemy state machine cancela TELEGRAPH/ATTACK/SKILL_* → RECOVERY + suma 1.5s a CDs. Player cancela `is_attacking`.
- **BENDICION vampire**: HitboxComponent._apply_bendicion_heal_to_source() cura attacker 5% HP máx. NO aplica status al defender.

### 4.4 Lecciones canon vigentes
- Edit pierde tabs → PowerShell `[char]9`.
- Variant inference con warnings-as-errors → tipar explícito `var X: Type = ...` para indexar constantes/dicts.
- Tests headless NO cargan autoloads (limitación pre-existente).
- Stats = Base + Equipo + Skills + Set.
- Bosses inherit Enemy + override _tick_state con boss state >= 100.
- Status effects: id es StringName, paths internos .tres pueden mismatch sin romper.
